# AI-103 手机刷题（个人自用）

手机上打开：`https://<你的用户名>.github.io/<仓库名>/`

- 题库以 **AES-256-GCM** 密文存放在 `public/bank.enc.js`，需要口令解锁；仓库里没有明文题目。
- 首次打开后可「添加到主屏幕」；Service Worker 会缓存应用，之后**离线也能刷**。
- 作答记录全部存在手机浏览器本地（localStorage），不上传任何服务器；换设备时用应用内「数据 → 导出/导入」搬迁。
- `public/offline.html` 是单文件离线版（密文内嵌），可另存到手机本地直接打开。

本仓库不含明文题目、不含答案、不含学习笔记。
